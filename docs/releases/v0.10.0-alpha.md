# v0.10.0-alpha · DSHA Root 后台副屏与小米超级岛

面向使用 **DSHA 且手机已 root** 的用户：通过配套插件方便地调用模块后台虚拟副屏，并在小米超级岛查看 Agent 的任务进展。

![真机界面](https://raw.githubusercontent.com/huantuoshen-prog/agent-mobile-use-hyperos/main/docs/images/v0.10/showcase.png)

## 下载与安装

- `agent-mobile-use-ksu-v0.10.0-alpha.zip`：在 KernelSU 管理器安装，包含控制台 APK、网关和副屏运行时；安装后重启并首次解锁。
- `dsh-mobile-use-0.3.0.zip`：在 DSHA 插件管理器导入，按提示重启 Web。
- `SHA256SUMS.txt` 和 `live-agent-0.10.0-manifest.json`：用于核对下载及包内二进制。

在模块控制中心允许发送通知并开启“超级岛通知（HyperOS）”。确认网关 ONLINE、LSPosed ACTIVE，DSHA 插件加载后先调用 `mobile_status`。本模块副屏不要求开启 DSHA Root Shell 或创建 DSHA 自带副屏。

## 本次更新

- 模块后台副屏与 DSHA 十五个工具接入，支持创建、回收、缩放、截图读屏、操作和前后台切换。
- 自动跟随宿主任务事件显示七种状态：进行中、前台控制、后台副屏、等待回答、完成、失败、停止。
- 真实提问复用单条等待胶囊，修复宽岛遮挡状态栏和重复问题通知。
- 修复 HyperOS 通知动作引用，停止按钮绑定当前会话/轮次并等待 DSHA 取消回执。
- 本机控制 token、Android 17 私有目录标签、首次解锁后交付、通知权限和偏好保留。
- 缩放接口返回实际硬件对齐后的尺寸；音频仅恢复本模块修改的设置。

## 已验证

Redmi K90 / HyperOS 4 / Android 17，KernelSU + LSPosed，DSHA build170 / DSH 0.2.0-rc.2。正式模型任务已验证模块副屏操作、前后台切换、截图读屏、提问与回答、完成通知、岛内停止和重启后的调用。19 项 Go 顶层测试、7 项 Node 测试、Java 82 项载荷检查及七状态检查通过。

## 升级与兼容范围

本版为 alpha 预发布。历史 APK 签名可能不同，普通设备无法保证直接覆盖；先保留旧构件与数据，安装脚本在 APK 安装失败时停止。本轮测试机具备核心签名破解，覆盖成功不代表其他设备也能跨签名升级。

其他 ROM、Android 版本和 root 管理器需分别验收。DSHA 自带副屏是独立通道；其 build170 的 NoSuchMethodException 未在本模块仓库修复。
