# v0.11.0-alpha 发布说明草稿

本版仍为本地候选构件，真机验收和公开发布尚未完成。配套 DSHA 插件为 `dsh-mobile-use 0.4.0`，目标宿主接口为 DSH `0.2.0-rc.2`。

## 新增

- 超级岛展开后二选一答题；多题逐题选择，完整答案通过宿主提问服务返回 Agent。
- 模块答题面板支持长问题、多选和自定义回答。DSHA 原生页面与岛内回答由同一个宿主请求选择最终结果。
- 控制台安装检查、私有连接凭据修复、`mobile_diagnose`，配套插件共 16 个工具。
- 手动检查更新、模块与插件配对显示；下载通过 SHA-256 后再选择保存位置，失败时清理缓存。
- 兼容 DSHA 旧版和独立持久数据目录，凭据交付与安装检查遵循宿主的数据位置记录。
- 集中版本配置、固定签名证书检查和模块安装前构件校验。

## 边界

岛内答题覆盖当前前台等待请求。超时后的 continued 问题、带 intent 的审核问题继续在 DSHA 处理。DSHA 自带虚拟屏与模块 Root 虚拟屏各自独立。

本地主机：12 项 Node 测试、27 项 Go 顶层测试通过；Java 原 82 项载荷检查、七状态检查、双按钮检查及下载校验失败路径检查通过。安装脚本语法与发布构件校验通过。候选 APK 公开证书与上一版一致。

测试手机已完成前一轮候选的覆盖安装和重启后模块哈希核对；DSHA Web 加载插件目录失败仍待修复。本轮目录兼容和下载流程修改尚未安装。SystemUI 按钮、实际 Agent 答案回传、安装检查页及完整重启恢复仍待验收。详细记录见 [开发与验收文档](../live-agent-0.11.md)。

## 发布后的升级顺序

在 KernelSU 安装模块 ZIP，重启并首次解锁；在 DSHA 插件管理器导入配套插件 ZIP并重启 Web；打开模块“安装检查”，执行只读副屏任务与宿主提问验收。候选更新索引当前保留在本机构建目录，公开发布前不更新在线索引。
