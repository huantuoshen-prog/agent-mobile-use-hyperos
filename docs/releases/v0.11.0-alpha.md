# v0.11.0-alpha · 超级岛答题与远程 Agent

本版为正式 Release，沿用 `v0.11.0-alpha` 标签和已校验的配套构件。配套 DSHA 插件为 `dsh-mobile-use 0.4.0`，远程 MCP 客户端为 `agent-mobile-use-remote 0.1.0-alpha`。DSHA 目标宿主接口为 DSH `0.2.0-rc.2`；远程 MCP 接入另已核验 DSH `0.2.1-rc.2`。

## 新增

- 超级岛展开后二选一答题；多题逐题选择，完整答案通过宿主提问服务返回 Agent。
- 模块答题面板支持长问题、多选和自定义回答。DSHA 原生页面与岛内回答由同一个宿主请求选择最终结果。
- 控制台安装检查、私有连接凭据修复、`mobile_diagnose`，配套插件共 16 个工具。
- 手动检查更新、模块与插件配对显示；下载通过 SHA-256 后再选择保存位置，失败时清理缓存。
- 兼容 DSHA 旧版和独立持久数据目录，凭据交付与安装检查遵循宿主的数据位置记录。
- 集中版本配置、固定签名证书检查和模块安装前构件校验。
- 独立远程 MCP 客户端 `0.1.0-alpha`：电脑/NAS 经 SSH/Tailscale 调用手机的 17 个工具，包含任务实况、停止和手机答题；增加独占控制租约及断线回收。见 [接入文档](../remote-access.md)。
- DSHA 插件文件、注册、激活结果诊断；修复通知结算延迟阻塞已收到答案的问题。
- 修复默认显示组的锁屏覆盖模块副屏：支持对应 Android 标志时，模块副屏使用独立显示组与独立解锁状态。
- 答题面板持续核对请求状态，Agent 确认接收后自动关闭，取消或过期的表单停止接受提交。

## 边界

岛内答题覆盖当前前台等待请求。超时后的 continued 问题、带 intent 的审核问题继续在 DSHA 处理。DSHA 自带虚拟屏与模块 Root 虚拟屏各自独立。

本地主机：19 项 Node 测试、32 项 Go 顶层测试及 Go vet 通过；Java 原 82 项载荷检查、七状态检查、双按钮检查及下载校验失败路径检查通过。远程流程使用实际 stdio 子进程和模拟手机网关验证。安装脚本语法与发布构件校验通过。候选 APK 公开证书与上一版一致。

测试手机已完成候选覆盖安装和重启后的模块哈希核对。DSHA Web 加载故障经修复 App SELinux 标签及重新启用插件后恢复；真实 DSHA 调用 mobile_status 成功，岛内选择已返回原会话。电脑经 SSH 完成副屏读屏、截图与手机答题，强杀客户端后约 31.9 秒自动回收。VPS 已部署 SSH 转发与 MCP 配置，其实际 SDK 发现并校验 17 个工具；用户手动提交的完整模型验收随后通过，11 次工具调用均成功，手机回答“验收通过”，任务以 completed 结束并确认回收。

SSH 等待首次解锁修正版已完成安装与重启验收，VPS 隧道自动恢复；Wi-Fi 断开约 56 秒后重新接入原地址，连接自动恢复，DSH 主进程保持运行。锁屏副屏修正后，已在主屏保持锁定和息屏的状态下完成设置页读屏、截图和回收。

180 秒锁屏后台复测完成读屏、截图、通知与回收；用户在手机端停止后，后续操作被拒绝。连续两题、多选“读屏/截图”和自定义文字 `panel-ok` 均已回传 VPS。新面板确认接收后自动关闭，30 秒超时退出及拒绝旧答案均通过真机验证。DSHA Web 在本轮重启后确认插件 0.4.0 注册了 16 个工具。

更长时间后台运行、NAS 独立 Agent、DSHA 原生界面竞争回答和其余取消组合仍待验收。手机当前网络遇到 GitHub API 匿名限流及 raw 域名解析问题，手机内下载保存未完成验收；可从本 Release 下载配套构件。详细记录见 [开发与验收文档](../live-agent-0.11.md)。

## 发布后的升级顺序

在 KernelSU 安装模块 ZIP，重启并首次解锁；在 DSHA 插件管理器导入配套插件 ZIP 并重启 Web；打开模块“安装检查”，执行只读副屏任务与宿主提问验收。远程 Agent 按接入文档配置 SSH/Tailscale 与独立 MCP 客户端。在线更新清单仅在 Release 构件上传、公开下载与哈希核对后切换到本版。
